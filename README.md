# Sito di PrintPrompt

Pubblicato su GitHub Pages: https://printprompt.github.io

- `it/`, `en/`, `es/`: home, privacy, condizioni, eliminazione account
- `m/`: pagina dei link ai profili dei maker (`/m/?id=...`)
- `.well-known/assetlinks.json`: collega il sito all'app (link verificati)
- `.nojekyll`: dice a GitHub di pubblicare i file così come sono
