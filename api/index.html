API per i negozi

Se vendi oggetti stampati in 3D o hai un gestionale, puoi mandare le richieste di stampa ai maker di PrintPrompt in automatico. Le richieste arrivano a tuo nome: le vedi anche nell'app, dove continui a parlare con il maker, accettare l'offerta e seguire la spedizione.

1. Crea una chiave

Nell'app: Profilo → API per negozi → Nuova chiave. La chiave inizia con pp_live_ e si vede una volta sola: copiala subito e tienila segreta (chi la ha può mandare richieste a tuo nome). Puoi revocarla quando vuoi.

2. Indirizzo e accesso

Tutte le chiamate vanno a:

https://xedohxavgzvzupabnawr.supabase.co/functions/v1/api/v1/…

con l'intestazione Authorization: Bearer pp_live_…. Le risposte sono in JSON. Limite: 300 chiamate l'ora per chiave.

3. Le chiamate

Metodo e percorsoA cosa serve
GET /makers/{id}Stampanti, materiali e consegne di un maker. L'id del maker è nel link del suo profilo (…/m/?id=…).
POST /requestsNuova richiesta di stampa.
GET /requestsLe tue ultime 100 richieste, con stato, prezzo e data.
GET /requests/{id}Una richiesta: stato (sent, offered, accepted, printing, ready, completed…), prezzo e data dell'offerta, corriere e codice di spedizione.

Nuova richiesta

curl -X POST "https://xedohxavgzvzupabnawr.supabase.co/functions/v1/api/v1/requests" \
  -H "Authorization: Bearer pp_live_LA_TUA_CHIAVE" \
  -H "Content-Type: application/json" \
  -d '{
    "maker_id": "ID-DEL-MAKER",
    "material": "PLA",
    "color": "nero",
    "quantity": 2,
    "delivery": "shipping",
    "file_url": "https://tuo-negozio.it/modelli/staffa.stl",
    "file_name": "staffa.stl",
    "notes": "Ordine #1234",
    "address": { "full_name": "Mario Rossi", "street": "Via Roma 1", "zip": "52100", "city": "Arezzo", "province": "AR", "phone": "" }
  }'
CampoNote
maker_idObbligatorio.
printer_idFacoltativo: se manca, usiamo la prima stampante del maker che stampa quel materiale.
materialObbligatorio, uno di quelli del maker (vedi GET /makers/{id}).
quantityDa 1 a 50.
deliverypickup (ritiro) o shipping (spedizione, serve address con CAP di 5 cifre).
file_url o file_base64Il file STL (binario o di testo), al massimo 30 MB. Il link deve essere https e pubblico.
notes, color, file_nameFacoltativi.

La risposta (201) contiene l'id della richiesta e le misure lette dal file (volume e ingombro). Il maker riceve un avviso e risponde con prezzo e data: controlla lo stato con GET /requests/{id}, ad esempio ogni ora.

Errori

Gli errori hanno la forma {"error": {"code": "…", "message": "…"}}: 401 chiave mancante o revocata, 400 dati o file non validi, 422 richiesta rifiutata (per esempio materiale non disponibile, oggetti vietati), 429 troppe chiamate.

Regole

Valgono le stesse condizioni d'uso dell'app: niente armi, parti di armi o oggetti vietati. I pagamenti si accordano con il maker nella chat dell'app.

English (short)

Create a key in the app (Profile → API for shops), then call https://xedohxavgzvzupabnawr.supabase.co/functions/v1/api/v1/ with Authorization: Bearer pp_live_…. Endpoints: GET /makers/{id}, POST /requests (fields as above, STL via file_url or file_base64, max 30 MB), GET /requests, GET /requests/{id}. Limit: 300 calls per hour per key. Requests appear in your account in the app, where you chat with the maker and accept the offer.
